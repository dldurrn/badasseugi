# 릴스 만드는 법

`scripts/make-reel.cjs` 가 맞춤법 문제은행에서 릴스 영상을 뽑습니다.
편집기를 열 일이 없습니다 — 문항 고르고 두 줄 적으면 완성된 mp4 가 나옵니다.

결과는 `insta/reel/` 에 들어갑니다. 이 폴더는 `.gitignore` 에 있어 저장소에 안 올라갑니다.

---

## 새 편 만들기 — 3단계

### 1단계 · 문항 고르기

```bash
node scripts/make-reel.cjs --list
```

문제은행 전체가 갈래별로 뜹니다. `✔` 는 이미 만든 것입니다.

```
[낫다/낳다]
  nat-1          감기가 다 ___어요.  → 나았
  nat-2          고양이가 새끼를 ___어요.  → 낳았
```

**어른이 스스로 틀린 것을 알아차리는 문항**을 고르세요. 저장과 공유가 거기서 납니다.
아이가 틀리는 것만 올리면 부모는 구경만 합니다.

### 2단계 · `REELS` 에 한 덩이 추가

`make-reel.cjs` 안의 `REELS` 배열에 넣습니다.

```js
{
  file: '6_낫다낳다',                    // 파일 이름
  id: 'nat-1',                          // --list 에서 고른 id
  format: 'dad',                        // 말투 (아래 참고)
  hook: ['감기 빨리 낳으세요?', '한 번쯤 받아보셨죠'],
  bonus: { wrong: '낳으세요', right: '나으세요' },
},
```

**`format`** — 말투 묶음입니다. `FORMATS` 에 정의되어 있고, 뼈대는 같고
위 꼬리표·아래 한 줄만 다릅니다. **같은 문항도 형식이 다르면 다른 편이 됩니다.**

| 형식 | 꼬리표 | 힌트 | 아래 한 줄 | 쓸 때 |
|---|---|---|---|---|
| `quiz` | 맞춤법 한 문제 | 3초 안에 골라보세요 | 없음 | 도달·저장을 노릴 때 |
| `dad` | 아빠도 틀렸습니다 😅 | 정답은 스와이프 → | 귀찮아서 만든 건데… | 어른이 틀리는 문항일 때 |

**새 형식을 만들려면** `FORMATS` 에 한 덩이 더 넣으면 됩니다.

```js
const FORMATS = {
  // …
  mom: {
    label: '엄마들이 제일 많이 묻는 것',
    hint: '정답은 스와이프 →',
    tail: '초등 1·2학년 받아쓰기 · 맞춤법',
  },
};
```

**`tail` 에 「앱」이라고 쓰지 마세요.** 스토어에 없는 물건이라
찾으러 갔다가 그냥 돌아옵니다. 「만든 건데」 「받아쓰기 공책」 처럼 쓰세요.

**`hook`** — 첫 2.6초에 뜨는 두 줄입니다. 여기서 넘길지 말지가 갈립니다.
둘째 줄이 크고 빨갛게 나오니 **센 말을 둘째 줄에** 두세요.
각 줄 12자 안팎, 넘으면 글자가 자동으로 줄어듭니다.

### 훅은 소리 내어 읽어 보고 넣으세요

짧게 쓰려다 말이 안 되는 문장이 자꾸 나옵니다. **실제로 걸렸던 것들:**

| 안 됨 | 왜 | 고침 |
|---|---|---|
| 받아쓰기 시험에 / 꼭 나오는 **자리**입니다 | 「자리」를 이렇게 안 씁니다 | 받아쓰기에서 / 아이들이 꼭 틀립니다 |
| 공공장소 안내문에도 / **자주 틀립니다** | 안내문이 틀리는 것처럼 읽힙니다 | 공공장소 안내문에서도 / 자주 보이는 실수입니다 |
| 아이 앞에서 / **아는 척했다가** | 문장이 끊겨 둘째 줄에 힘이 안 실립니다 | 아이 앞에서 아는 척했다가 / 조용히 검색했습니다 |

규칙 셋입니다.

1. **둘째 줄로 문장이 끝나야 합니다.** 「…했다가」처럼 흐리면 punch 가 없습니다.
2. **주어가 분명해야 합니다.** 누가 틀리는 건지 헷갈리면 안 됩니다.
3. **어려운 명사로 줄이지 마세요.** 「자리」 「부분」 「구간」 같은 말로 압축하면
   짧아지는 대신 말이 어색해집니다. 차라리 동사로 끝내세요 — 「꼭 틀립니다」.

형식마다 훅의 성격이 다릅니다.

| 형식 | 훅이 말하는 것 | 예 |
|---|---|---|
| `quiz` | **아이가** 왜·얼마나 틀리는지 | 저학년이 여기서 / 제일 많이 넘어집니다 |
| `dad` | **내가** 틀렸다는 고백 | 아이 숙제 봐주다 / 제가 먼저 틀렸습니다 |

**`bonus`** — 「왜」 장면 아래 상자입니다. 두 가지 모양이 됩니다.

| 쓰는 법 | 나오는 모양 | 언제 |
|---|---|---|
| `{ wrong: '설레임', right: '설렘' }` | 두 칸 비교 (틀린 표기 / 바른 표기) | 짝이 있을 때 — **대개 이쪽** |
| `'ㄵ 앉다   ㄺ 맑다   ㅄ 값'` | 초록 상자 한 줄 | 짝이 아니라 목록일 때 |

문제·정답·설명은 문제은행에서 자동으로 옵니다. **손으로 옮겨 적지 마세요** —
두 벌이 되면 언젠가 앱과 릴스의 설명이 달라집니다.

### 3단계 · 뽑기

```bash
node scripts/make-reel.cjs --reel=4
```

`--reel=` 뒤 숫자는 `REELS` 에서 **몇 번째인가**입니다. 1분쯤 걸립니다.

## 명령어

| 명령 | 하는 일 |
|---|---|
| `node scripts/make-reel.cjs` | `REELS` 전부 |
| `node scripts/make-reel.cjs --reel=2` | 둘째 편만 |
| `node scripts/make-reel.cjs --list` | 문제은행 보기 |
| `node scripts/make-reel.cjs --only=answer,why,cta` | 그 장면만 짧게 (`_sample.mp4`) |

장면 이름은 `hook` `count` `answer` `why` `cta` 입니다.
**고친 자리만 빨리 보고 싶을 때** `--only=` 를 쓰세요. 전체를 매번 뽑으면 오래 걸립니다.

## 템포 바꾸기

`TIMELINE` 의 숫자(초)만 고치면 됩니다.

```js
const TIMELINE = [
  { name: 'hook',   draw: sceneHook,   dur: 2.6 },
  { name: 'count',  draw: sceneCount,  dur: 3.0 },   // 3·2·1 — 1초씩이라 3.0
  { name: 'answer', draw: sceneAnswer, dur: 3.8 },
  { name: 'why',    draw: sceneWhy,    dur: 3.4 },
  { name: 'cta',    draw: sceneCta,    dur: 2.8 },
];
```

**효과음은 따라옵니다.** 시각을 손으로 적지 않고 장면 시작에서 계산하기 때문입니다
(`buildSfx`). 예전에는 1.5초·4.9초처럼 박아 두어, 훅을 늘리자 틱이 카운트다운보다
먼저 울렸습니다.

`count` 는 1초에 하나씩 세므로 **3.0 을 유지**하세요. 2.4 로 줄이면 「1」이 안 나옵니다.

## 인스타에 올릴 때

1. 릴스 → mp4 선택
2. **음원 추가** — 릴스는 음원이 붙어야 배포가 붙습니다. 조용한 곡, 볼륨 20~30%.
   효과음이 묻히면 안 됩니다
3. **커버** — 첫 장면(질문 뜬 화면). `_표지.png` 가 그 장면입니다
4. 하루 한 편씩, 밤 9~10시

## 자주 막히는 곳

**「문항을 못 찾았습니다」** — `id` 오타입니다. `--list` 로 다시 확인하세요.

**보기가 셋인 문항** — 상자가 자동으로 낮아지고 카운트다운 원이 내려옵니다(`layout()`).
따로 할 일 없습니다.

**낱말이 상자를 넘음** — 자동으로 줄어듭니다. 그래도 어색하면 `bonus` 를 짧게 쓰세요.

**「전부 무료」라고 쓰지 마세요** — 안내 장면 주석에 이유가 적혀 있습니다.
릴스는 지워지지 않고 캡션은 고쳐도 영상에 박힌 글자는 못 고칩니다.
`plan.ts` 가 영구히 안 잠그기로 한 것(원고지·채점·오답노트·내장 문제은행)만 이름을 댑니다.

**받아쓰기 문항은 안 됩니다** — 이 스크립트는 맞춤법 문제은행(`spelling-bank.ts`)만 읽습니다.
받아쓰기는 2지선다가 아니라 받아쓰는 것이라 이 형식에 안 맞습니다.
