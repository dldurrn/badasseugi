# 참고 자료

이 폴더는 개발 참고용입니다. 빌드에 포함되지 않습니다.

## 이전 프로토타입

기획 검증에 사용한 단일 파일 프로토타입이 있었습니다.
그 채점 로직은 이미 `src/lib/grading.ts`로 옮기면서
오류 유형을 4개에서 6개로 늘리고 테스트를 붙였습니다.

프로토타입에서 발견해 고친 문제들 (같은 실수를 반복하지 마세요):

1. **세션 전환 버그** — 결과 화면에서 "틀린 것만 다시"를 눌러도 반응이 없었습니다.
   같은 컴포넌트가 재사용되면서 이전 상태가 남았기 때문입니다.
   → 새 세션마다 컴포넌트를 새로 마운트하도록 처리했습니다.

2. **중도 이탈이 기록에 반영됨** — 오답 연습을 몇 개만 풀고 나가도 별이 올라갔습니다.
   → `onComplete`는 마지막 문제를 마친 경우에만 호출됩니다.

3. **같은 날 몰아서 졸업** — 연속 2회 조건을 같은 날 두 번으로 채울 수 있었습니다.
   → `lastCorrectDate`를 비교해 다른 날에만 별을 줍니다.

4. **채점 결과 비교가 어긋남** — 내가 쓴 줄과 정답 줄을 따로 그려서
   길이가 다르면 세로로 어긋났습니다.
   → 정렬된 열(column)을 세로 기둥으로 세워 위아래를 맞췄습니다.

5. **입력창 맞춤법 밑줄** — 브라우저가 틀린 맞춤법에 빨간 밑줄을 그어
   정답을 미리 알려줬습니다.
   → `spellCheck={false}` 등으로 껐습니다.

6. **실수로 제출됨** — "확인"을 누르면 바로 채점됐습니다.
   → 최종 확인 단계를 넣었습니다.
