짧은 문장은 잘 쓰는데 문장이 길어지면 중간을 빼먹거나 순서가 바뀌는 아이가 많아요. 받침을 몰라서가 아니라 기억이 흘러서 생기는 일이에요. 긴 문장을 끊어 듣는 연습법과 연습 문장 10개를 정리했어요.

왜 긴 문장에서 틀릴까

  • 한 번에 기억할 수 있는 양이 정해져 있어서, 문장이 길면 앞부분이 흐려져요.
  • 쓰는 데 정신을 쓰다 보면 뒤에 들은 말이 사라져요.
  • 마침표까지 한 호흡으로 듣는 연습이 부족해요.

끊어 듣는 3단계

  1. 뜻 덩어리로 끊어요. 「누가 / 어디서 / 무엇을 / 어떻게」처럼 의미 단위로 잘라요.
  2. 끊은 곳을 마음속으로 하나, 둘, 셋 세며 기억해요.
  3. 덩어리마다 한 번에 쓰고, 다 쓴 뒤 처음부터 소리 내어 읽으며 확인해요.

연습 문장 10개 (끊어 읽는 자리 표시)

번호문장 (/ 는 끊어 읽는 자리)
1우리 가족은 / 주말마다 / 가까운 공원에서 / 산책을 해요.
2비가 많이 와서 / 오늘은 / 운동장에서 놀지 못했어요.
3동생이 / 아끼던 장난감을 / 친구에게 빌려주었어요.
4엄마가 / 시장에서 / 싱싱한 채소와 과일을 / 잔뜩 사 오셨어요.
5겨울이 되면 / 두꺼운 옷을 입고 / 따뜻한 차를 마셔요.
6나는 / 쉬는 시간에 / 친구들과 줄넘기를 하며 / 신나게 놀았어요.
7할머니 댁에 가면 / 마당에서 / 닭이 모이를 먹는 모습을 볼 수 있어요.
8아침에 일어나서 / 세수를 하고 / 밥을 먹은 뒤에 / 학교에 갔어요.
9책을 많이 읽으면 / 아는 것이 늘고 / 글도 잘 쓰게 돼요.
10눈이 오는 날에는 / 친구들과 / 눈사람을 만들며 / 즐겁게 놀아요.

받침은 7번 「닭」, 9번 「읽으면」(겹받침), 8번 「먹은」에서 짚어 주세요.

부모님이 불러 줄 때

  • 문장을 이어서 두 번 읽어 주세요. 처음에는 뜻을, 두 번째는 쓰면서 확인하는 용도예요.
  • 끊어 읽는 자리에서 짧게 숨만 쉬세요. 낱말마다 끊으면 소리가 어색해져서 오히려 못 들어요.
  • 다 쓴 뒤에는 정답과 나란히 놓고 빠진 덩어리가 있는지 먼저 확인하세요.

앱에서도 연습할 수 있어요

받아쓰기 공책에는 문장을 끊어서 들려주는 읽기 방식이 있어요. 긴 문장이 어려우면 끊어 읽기를 고르고, 익숙해지면 이어 읽기로 바꿔 보세요. 읽는 속도도 문장마다 조절할 수 있어요.
