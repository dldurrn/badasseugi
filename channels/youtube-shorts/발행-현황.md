# 유튜브 쇼츠 — 발행 현황

채널에 올린 영상: **아직 없음** (2026-10-27 기준)

## 이 폴더에 든 것
```
youtube-shorts/
├─ 1차/ ~ 5차/ · 6차-투표형/ · 7차-투표형/ · 8차-투표형/   ← 인스타 릴스 24편의 쇼츠용 (영상 이름은 인스타와 같음)
└─ 기능소개/   ← 1_채점표.mp4 (앱 채점 화면 시연, 실제 앱 영상)
```
- 영상 끝(마지막 3.2초)이 **유튜브용 아웃트로**입니다: 「설명란 링크에서 바로 풀어보세요 · badasseugi.com」 + 구독 한 줄.
  인스타용(`channels/instagram/아웃트로/outro_badasseugi.mp4`)은 「프로필 링크」라서 유튜브에 안 맞아 따로 만들었습니다.
- 유튜브 아웃트로 원본: `channels/instagram/아웃트로/outro_youtube.mp4` (`node scripts/make-reel.cjs --make-outro=youtube` 로 다시 뽑음).
- **새 릴스를 뽑으면** `scripts/make-reel.cjs` 가 인스타용과 함께 `channels/youtube-shorts/<--out 값>/` 에 쇼츠용도 자동으로 만듭니다(`--no-youtube` 로 끔).
- 영상·이미지는 git 에 안 들어갑니다.

## 올릴 때
- 제목 끝이나 설명에 `#Shorts`, **설명란 첫 줄에 `https://badasseugi.com`**, 같은 링크를 **고정 댓글**에도 적습니다(영상 속 글자는 눌러지지 않습니다).
- 제목·설명은 `channels/naver-clip/클립-글.md` 를 바탕으로 쓰면 됩니다(인스타의 「프로필 링크」 문구는 빼기).

## 알아 둘 것
- **본편 화면에는 인스타 계정명(@badasseugi_note)과 아래 한 줄 안내가 그려져 있습니다.** 유튜브 채널 이름이 다르면 어색할 수 있습니다. 새로 뽑는 릴스부터는 계정명을 바꿔 그릴 수 있게 고칠 수 있습니다(기존 24편은 다시 뽑아야 합니다).
- 유튜브 쇼츠 길이 제한은 확인하지 못했습니다(영상은 15~16초라 짧습니다).

## 기능 소개(앱 화면) 영상
- `기능소개/1_채점표.mp4` 만 있습니다. 끝의 옛 CTA 장면("프로필 링크", "무료로 씁니다")을 유튜브용 아웃트로로 바꿨습니다.
- 인스타에 올린 나머지 기능 소개 4편(손으로 치세요 · 오답노트 · 듣고 고르기 · 부모 리포트)은 **원본 파일이 저장소에 없어서 아직 없습니다.** 원본 mp4 를 주시면 같은 방식으로 추가합니다.
