# 네이버 블로그 태그 한 번에 넣기 (북마클릿)

네이버 태그 칸은 붙여 넣기가 안 돼서, 태그를 하나 넣고 Enter 치는 동작을 대신 반복해 주는 **크롬 북마크 버튼**입니다.
(2026-10 다른 세션에서 만들었고 저장소에는 없었습니다. 크롬 북마크바의 「네이버 태그」가 이것입니다.)

## 한 번만 설정
1. Chrome 북마크바의 빈 곳을 오른쪽 클릭 → **페이지 추가**
2. 이름: `네이버 태그`
3. URL 칸에 아래 코드를 **한 줄 그대로** 붙여 넣고 저장

```
javascript:(async()=>{let d=document,el=d.activeElement;while(el&&el.tagName==='IFRAME'){try{d=el.contentDocument;el=d.activeElement}catch(e){break}}if(!el||!/INPUT|TEXTAREA/.test(el.tagName)){alert('태그 입력칸을 먼저 한 번 클릭한 뒤 눌러 주세요');return}const raw=prompt('태그를 붙여 넣으세요 (#태그 #태그 또는 쉼표로)');if(!raw)return;const tags=raw.split(/[\s,#]+/).filter(Boolean);const set=Object.getOwnPropertyDescriptor(Object.getPrototypeOf(el),'value').set;const w=ms=>new Promise(r=>setTimeout(r,ms));for(const t of tags){el.focus();set.call(el,t);el.dispatchEvent(new Event('input',{bubbles:true}));for(const type of ['keydown','keypress','keyup'])el.dispatchEvent(new KeyboardEvent(type,{key:'Enter',code:'Enter',keyCode:13,which:13,bubbles:true}));await w(150)}})();
```

## 글 올릴 때마다
1. 네이버 블로그 글쓰기 화면에서 **태그 입력칸을 한 번 클릭**
2. 북마크바의 **「네이버 태그」** 클릭
3. 뜬 창에 `발행-안내.md` 의 `태그(10개):` 줄을 **그대로** 붙여 넣고 확인
   (`#`이 붙어 있어도, 쉼표로 나뉘어 있어도 알아서 자릅니다)

2026-10 에 낫다/낳다 글로 써 보고 태그가 준비한 목록과 일치함을 확인했습니다.
북마크바에 안 보이면 Ctrl+Shift+B 로 북마크바를 켜거나, 크롬 북마크 관리자(Ctrl+Shift+O)에서 `네이버 태그`를 찾아보세요.
