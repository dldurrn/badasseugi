'학생으로서'일까 '학생으로써'일까요? 자격인지 도구인지만 물어보면 바로 구분되는 방법을 정리했어요.



한 줄로 정리하면


「로서」는 신분·자격(학생으로서, 형으로서), 「로써」는 수단·도구·재료(말로써, 연필로써)를 나타냅니다.



이렇게 확인해 보세요


• 「누구로서」인지(자격) → 로서

• 「무엇으로」 하는지(도구·방법) → 로써


• 학생(으로서/으로써) 규칙을 지켜요 — 학생이라는 자격 — 학생으로서 규칙을 지켜요

• 말(로서/로써) 마음을 전해요 — 말이라는 방법 — 말로써 마음을 전해요

• 형(으로서/으로써) 동생을 도와요 — 형이라는 자격 — 형으로서 동생을 도와요



외우기 쉬운 방법


• 자격(학생·반장·부모·형)은 「로서」

• 도구·방법(말·글·연필·칼)은 「로써」

• 받침이 있으면 「으로서/으로써」, 받침이 없거나 ㄹ 받침이면 「로서/로써」예요



자주 틀리는 모양


• 학생으로써 규칙을 지켜요 — 학생으로서 규칙을 지켜요

• 말로서 마음을 전해요 — 말로써 마음을 전해요

• 반장으로써 책임을 다할게요 — 반장으로서 책임을 다할게요

• 연필로서 그림을 그렸어요 — 연필로써 그림을 그렸어요



연습 문제 5개


괄호 안에서 알맞은 것을 골라 보세요. 정답은 아래에 있어요.


1. 학생(으로서/으로써) 규칙을 지켜요.

2. 연필(로서/로써) 그림을 그렸어요.

3. 반장(으로서/으로써) 책임을 다할게요.

4. 말(로서/로써) 천 냥 빚을 갚는다.

5. 누나(로서/로써) 동생을 돌봐요.


정답


1. 으로서 (자격)

2. 로써 (도구)

3. 으로서 (자격)

4. 로써 (방법)

5. 로서 (자격)
