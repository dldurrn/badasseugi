# 네이버 글 링크 수정표

네이버에 이미 올린 글은 「함께 보면 좋은 글」이 **링크 없는 글자**입니다(올릴 때 다른 글의 네이버 주소를 몰랐습니다). 아래 표대로 글마다 연결하세요.

**하는 법**: 네이버 블로그에서 그 글을 열고 **수정** → 「함께 보면 좋은 글」 아래 글 제목을 드래그로 선택 → 링크 버튼(또는 Ctrl+K) → 주소 붙여 넣기 → 확인 → 글 **발행**.
주소는 `네이버-주소.md` 와 같고, 이 표에서 복사하면 됩니다. 글 한 편에 2개 안팎이고, 모두 56개(글 28편)입니다.

- 아직 네이버에 안 올린 글(30번 등)을 가리키는 링크는 표에서 뺐습니다. 올린 뒤에 그 글과 연결된 글에서 링크를 더하세요.
- 29번은 새 파일로 올리면 링크가 이미 걸려 있습니다(수정표에 없음).
