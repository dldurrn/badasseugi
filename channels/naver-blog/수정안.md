# 네이버 블로그 수정안 (2026-11-03)

근거: 10월 유입분석(검색어 159개 묶음). 새 글이 아니라 **이미 올린 글에 검색어를 더하는** 작업이라 가장 빠르고 확실합니다.
기존 글은 **제목을 바꾸지 않는 글**(조회가 높음)과 **바꾸는 글**(조회가 낮음)로 나눴습니다.

## 하는 방법 (모든 글 공통, 글당 3분)

1. 블로그 → 해당 글 열기 → **수정**
2. 제목을 바꿀 글이면 제목 칸을 지우고 아래 **새 제목**을 붙여 넣기
3. 본문 맨 아래 「함께 보면 좋은 글」 **바로 위** 빈 줄을 눌러 아래 **붙여 넣을 문단**을 붙여 넣기 (굵은 글씨는 필요 없습니다)
4. **발행** 누르면 설정 창이 뜹니다. 태그 입력칸을 한 번 누르고 북마크 「블로그태그」를 눌러 **태그 10개**를 붙여 넣기 → 발행

> 태그는 새로 10개를 넣는 방식입니다. 기존 태그는 지워도 됩니다(검색어 기준으로 다시 정리한 목록입니다).

## 1. 되/돼 (08번) — 제목 그대로

조회 43 (높음), 검색어 변형이 가장 다양한 글입니다.

**붙여 넣을 문단** (「함께 보면 좋은 글」 위):

```
이런 문장에서 많이 헷갈려요

검색해서 많이 찾는 문장들이에요. 모두 「되어」를 넣어 보면 풀립니다.

• 봐도 돼요 — 봐도 되어요가 되니까 「돼」
• 이거 주면 돼 — 주면 되어가 되니까 「돼」
• 문이 열려 돼 있다 — 「되어 있다」의 준말이라 「돼 있다」로 띄어 써요. 「되있다」는 틀려요
• 약속이 취소돼서 — 취소되어서가 되니까 「돼서」
• 있어도 돼요 — 「되요」는 틀려요
• 어떡하면 되겠니 — 「되어겠니」는 말이 안 되니까 「되」
• 그러면 안 돼 — 안 되어가 되니까 「돼」

「돼요」「돼서」「돼」처럼 어미가 바로 붙는 자리는 대부분 「돼」이고, 「되겠다」「되고」「되는」처럼 뒤에 이어지는 말이 붙으면 「되」입니다.
```

**태그 10개:**
`되돼구분 되돼 봐도돼 돼있다 되돼구분법 초등맞춤법 맞춤법 초등받아쓰기 받아쓰기 받아쓰기공책`

## 2. 자주 틀리는 맞춤법 (14번) — 제목 바꾸기

조회 2 (낮음). 「설겆이 설거지」로 들어오는데 제목 앞쪽에 그 말이 없습니다.

**새 제목:**
```
설겆이 설거지 | 며칠 몇일 오랜만 봬요, 어른도 틀리는 맞춤법
```

**붙여 넣을 문단:**

```
설겆이 설거지, 어느 쪽이 맞나요

정답은 「설거지」예요. 「설겆이」는 예전에 쓰던 표기라 지금은 틀린 표기로 봅니다. 「설거지를 하다」「설거지하다」처럼 쓰고, 「설겆이」「설것이」로 쓰지 않아요.

• 설겆이를 했어요 → 설거지를 했어요
• 설것이 끝났어요 → 설거지가 끝났어요

며칠도 같이 확인해 두세요. 「몇일」이 아니라 「며칠」이 맞아요.
```

**태그 10개:**
`설겆이설거지 설겆이 며칠몇일 자주틀리는맞춤법 헷갈리는맞춤법 오랜만 봬요 어른맞춤법 맞춤법 받아쓰기공책`

## 3. 낫다 낳다 (20번) — 제목 그대로

조회 7. 「나았어요 낫어요」가 검색어에 나옵니다. 제목에 이미 「나았어요」가 있어서 본문과 태그만 더합니다.

**붙여 넣을 문단:**

```
「낫어요」「낫아요」는 어떻게 써야 할까요

「낫다」는 뒤에 모음이 오면 ㅅ이 사라지는 말이에요. 그래서 「낫어요」「낫아요」는 틀리고, 「나아요」「나았어요」가 맞아요.

• 감기가 낫어요 → 감기가 나아요
• 감기가 낫아서 → 감기가 나아서
• 상처가 금방 낫으면 → 상처가 금방 나으면
• 다 낫었어요 → 다 나았어요

자음이 뒤에 오면 ㅅ이 그대로 살아요. 「감기가 낫고」「금방 낫는다」「나으면 낫습니다」처럼요. 모음이 붙을 때만 ㅅ이 빠진다고 기억하세요.
```

**태그 10개:**
`낫다낳다 낫다낳다구분 나았어요낫어요 낫어요 낫아요 나았어요낳았어요 초등맞춤법 헷갈리는맞춤법 받아쓰기공책 받아쓰기`
