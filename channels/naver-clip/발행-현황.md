# 네이버 클립 — 발행 현황

올린 것: **1·2·3차**(릴스 9편) — 마지막으로 올린 편은 3차 3편 「갔다」(2026-10-27 사용자 말)
남은 것: **4차 ~ 10차 21편** (아래 폴더에 영상과 설명문이 들어 있음)

## 폴더
```
naver-clip/
├─ 4차/ · 5차/ · 6차-투표형/ ~ 10차-투표형/   편마다 <이름>.mp4 + <이름>.txt
├─ 기능소개/           1_채점표.mp4 + .txt (앱 채점 화면 시연, 실제 앱 영상)
├─ 클립-글.md          24편 전체의 제목·설명·연결할 글(원본)
└─ 발행-현황.md        이 문서
```
- 영상은 인스타 릴스와 같고 **끝 3.2초만 클립용 아웃트로**입니다(「콘텐츠 링크에서 자세히 보세요 · badasseugi.com」).
- `.txt` 는 **제목 / 콘텐츠 링크로 연결할 글 / 설명** 세 덩어리입니다. 설명을 통째로 복사해 붙이세요. 영상·이미지는 git 에 안 들어갑니다.
- 새 릴스를 `scripts/make-reel.cjs` 로 뽑으면 `naver-clip/<--out 값>/` 에도 클립용 영상이 자동으로 만들어집니다(`--no-naver` 로 끔). 설명문 txt 는 아직 자동으로 만들지 않습니다.

## 올릴 때
1. 영상(mp4) 올리기 → 2. 제목 붙여넣기 → 3. 설명 붙여넣기 → 4. **콘텐츠 링크**에 txt 에 적힌 블로그 글 연결.
2. 올린 뒤 이 문서와 `클립-글.md` 의 현황을 고칩니다.

## 기능 소개(앱 화면) 영상
- `기능소개/1_채점표.mp4` 만 있습니다. 이 영상 끝의 옛 CTA 장면("프로필 링크", "무료로 씁니다")을 클립용 아웃트로로 바꿨습니다.
- 인스타에 올린 나머지 기능 소개 4편(손으로 치세요 · 오답노트 · 듣고 고르기 · 부모 리포트)은 **원본 파일이 저장소에 없어서 아직 없습니다.** 원본 mp4 를 주시면 같은 방식으로 추가합니다.
