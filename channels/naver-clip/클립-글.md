# 네이버 클립 — 릴스 1~8차 클립 글

인스타 릴스를 네이버 클립에 올릴 때 쓰는 **클립 설명·제목·해시태그** 모음입니다.
인스타 캡션(`instagram/릴스/<차수>/캡션.md`)을 클립용으로 고쳤습니다.

## 인스타 캡션과 다른 점
- 네이버 클립에는 **프로필 링크가 없습니다.** 4차 이후 영상은 아웃트로를 클립용(「콘텐츠 링크에서 자세히 보세요」)으로 바꿨고,
  설명 끝에 **"아래 콘텐츠 링크의 글에서 받아쓰기 공책을 자세히 볼 수 있어요"** 를 넣었습니다.
  → 클립을 올릴 때 **콘텐츠 링크로 블로그 글을 하나 연결**하세요(아래 각 클립의 「연결할 글」 추천).
- 인스타의 점 세 줄(정답 접기)은 뺐습니다. 클립은 영상에서 답이 나오고, 설명은 해설 용도입니다.
- 투표형(6~8차)은 "댓글에 번호로" 문구를 그대로 둡니다.
- 길이·글자 수 제한은 Claude 가 네이버 클립 화면을 열어 볼 수 없어 확인하지 못했습니다. 올리는 화면에서 넘치면 해설 부분을 줄이세요.

## 영상·설명문 폴더
**4차 이후(아직 안 올린 15편)는 클립용 영상과 설명문이 폴더에 같이 들어 있습니다**: `channels/naver-clip/<차수>/<이름>.mp4` + `<이름>.txt`(제목·연결할 글·설명을 복사해 붙이면 됩니다).
영상 끝에는 **클립용 아웃트로**(「콘텐츠 링크에서 자세히 보세요 · badasseugi.com」)가 붙어 있습니다. 1~3차는 이미 올려서 만들지 않았습니다.

## 연결할 글 고르는 기준
- 기본은 **앱 소개(06)** — 클립을 본 사람이 앱을 처음 알게 되는 글입니다.
- 받침·ㅅ 계열(같아요·갔다·촛불·바닷가 …)은 **받침 글(05)**, 소리가 같은 말(짖어요·지어요)은 **개 게 새 세 글(11)** 이 내용상 이어집니다.
- 블로그 글 주소는 네이버 블로그를 열 수 없어 적지 않았습니다. 클립 올릴 때 글 목록에서 직접 고르세요.
