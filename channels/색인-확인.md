# 올리기 · 색인 확인 가이드

채널마다 올리는 순서와 간격, 올린 뒤 검색에 잡혔는지 확인하는 방법, 글별 확인 기록을 한곳에 둡니다.
**올린 날짜는 각 채널의 `발행-현황.md`, 이 문서는 "어떻게 올리나 / 잡혔나"** 입니다.

| 채널 | 현황 | 올리는 법 |
|---|---|---|
| 인스타그램 | `instagram/발행-현황.md` | 아래 1 |
| 네이버 클립 | (아직 안 올림) | 아래 2 |
| 티스토리 | `tistory/발행-현황.md` | 아래 3 |
| 네이버 블로그 | `naver-blog/발행-현황.md` | 아래 4 |

---

## 1. 인스타 릴스 올리기

1. 영상은 `instagram/릴스/<차수>/` 의 mp4. **인스타에서 내려받지 말고** 이 원본을 씁니다(워터마크 없음). 끝에 아웃트로가 붙어 있습니다.
2. 음원은 조용한 곡 **20~30%** — 효과음이 묻히면 안 됩니다. 비즈니스 계정은 상업용 음원만 써서 인기곡이 안 보일 수 있습니다.
3. 커버는 같은 폴더의 `_표지.png`(훅이 다 뜬 장면).
4. 캡션은 `캡션.md` 에서 복사. **점(`.`) 세 줄이 살아 있는지** 확인합니다 — 인스타가 빈 줄을 지웁니다.
5. 투표형(6차~)은 영상 정답 번호와 캡션 번호가 같은지 본 뒤 올립니다(보기를 뒤집은 편이 있습니다).
6. **올린 뒤 30분 안의 댓글에 전부 답글.** 댓글이 늘어야 더 퍼집니다.
7. 올린 뒤 `instagram/발행-현황.md` 에 조회수를 적습니다.

## 2. 네이버 클립 올리기

1. 같은 mp4(9:16, 15초대)를 그대로 씁니다. 인스타에 먼저 올린 뒤에 올립니다.
2. 아웃트로의 **"프로필 링크에서 바로 풀어보세요"는 인스타 기준 문구**입니다. 클립 설명이나 고정 댓글에 `badasseugi.com` 을 적어 보완합니다.
3. 파일에는 효과음만 있고 음악이 없습니다. 클립 편집기의 음원을 쓰거나 그대로 올립니다.
4. 해시태그는 검색어 위주로: `#초등받아쓰기 #초등맞춤법 #받아쓰기`
5. 블로그 글과 이어 붙일 수 있는 영상: **기능소개 `1_채점표`** ↔ 블로그 10번(원고지)·06번(앱 소개).
6. 길이·정책 등 네이버 클립의 제한은 Claude 가 화면을 열어 볼 수 없습니다(사이트 제한). **올리는 화면의 안내 문구를 직접 확인**하세요.
7. 올린 뒤 이 문서 아래 「네이버 클립 기록」에 적습니다.

## 3. 티스토리 올리기 (먼저)

- 붙여 넣을 파일: `tistory/<글>/tistory.html`, 제목·카테고리·슬러그·태그·이미지 순서는 같은 폴더의 `발행-안내.md`.
- **슬러그는 반드시 그대로** — 글끼리 링크가 이 주소를 씁니다.
- **티스토리가 먼저** 나갑니다. 네이버는 **티스토리 글이 구글에 색인된 것을 확인한 뒤**(보통 3일 안팎). 원본이 먼저 잡히게 하려는 것이라, 색인이 확인되면 3일을 기다릴 필요는 없습니다.

## 4. 네이버 블로그 올리기 (티스토리 글이 색인된 뒤)

- 붙여 넣을 파일: `naver-blog/대기/<글>/naver-editor.html` → **Chrome 으로 열어** Ctrl+A, Ctrl+C → 스마트에디터 본문에 Ctrl+V. 제목·태그·이미지 순서는 `발행-안내.md`.
  (스마트에디터는 margin·padding·border·배경색을 버려서, 예전 `naver.html` 은 간격·소제목이 무너졌습니다. `naver-editor.html` 은 빈 줄·굵은 큰 글씨·"• " 목록으로 풀어 써서 붙여 넣은 그대로 나옵니다 — 2026-10-21 09번으로 확인.)
- 배경색이 칠해진 「▶ [이미지 …]」 줄 자리에 이미지를 올리고 **그 줄은 지웁니다.** 맨 위 이미지는 **대표 사진**으로 지정.
- **공개** 상태로 발행(비공개·이웃공개면 색인이 안 됩니다).
- 하루 **한 편**씩. 올린 뒤 폴더를 `대기/` → `올림/` 으로 옮기고 `naver-blog/발행-현황.md` 를 고칩니다.
- 앞으로 만드는 글은 `scripts/build-blog-posts.cjs` 가 `naver-editor.html` 만 만듭니다(01~08번은 예전 `naver.html` 로 올렸습니다).

## 5. 색인 확인하는 법

Claude 는 네이버를 열지 못하므로(사이트 제한) **직접 확인해서 아래 표에 적어 주세요.**

### 확인 주기
올린 뒤 **3일 · 7일 · 14일**. 14일이 지나도 없으면 아래 「안 잡힐 때」.

### 티스토리 (구글)
1. Google Search Console → **URL 검사**에 글 주소를 넣습니다.
2. "URL이 Google에 등록되어 있음"이면 색인된 것입니다.
3. 아니면 같은 화면의 **색인 생성 요청**을 누릅니다.

### 네이버 (블로그 · 티스토리 둘 다)
1. **검색으로 확인**: 네이버 검색창에 글 제목을 큰따옴표로 감싸 검색합니다. 블로그 탭에 뜨면 잡힌 것입니다. (네이버는 `site:` 검색이 불안정해 제목 검색이 확실합니다.)
2. **서치어드바이저**(searchadvisor.naver.com)에서 사이트를 등록하고 **웹 페이지 수집 요청**을 합니다. 티스토리는 소유 확인이 필요합니다. 네이버 블로그 주소를 등록할 수 있는지는 **직접 확인이 필요**합니다.
3. **블로그 통계 → 유입분석**에서 검색 유입이 잡히는지 봅니다(색인된 뒤 실제로 검색으로 들어온 기록).

### 안 잡힐 때
- 공개 상태인지, 발행이 실제로 됐는지 먼저 봅니다.
- 같은 내용이 짧은 간격으로 중복되지 않았는지(티스토리 글이 색인되기 전에 네이버에 올리지 않았는지) 확인합니다.
- 서치어드바이저·Search Console 에서 수집/색인 요청을 다시 합니다.
- **글을 지웠다 다시 올리지 마세요** — 주소가 바뀌어 처음부터 다시 기다립니다.
- 네이버는 새 블로그의 색인이 느립니다(며칠~몇 주). 14일까지는 기다려 봅니다.
