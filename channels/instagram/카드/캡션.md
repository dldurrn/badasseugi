## 01 · 며칠 / 몇일

```
"오늘이 몇일이에요?"

이 문장, 어디가 틀렸을까요?

정답은 "며칠"입니다.
사실 "몇일"이라는 말은 국어에 아예 없어요.
"몇 월 며칠"처럼 언제나 "며칠"로 씁니다.

어른도 열에 여덟은 "몇일"이라고 쓰는 말이에요.
아이한테 물어보기 전에 먼저 확인해 보세요 🙂
```

## 02 · 되 / 돼

```
"커서 무엇이 되고 싶니?"
"커서 무엇이 돼고 싶니?"

어느 쪽일까요?

정답은 "되고".
"돼"는 "되어"를 줄인 말이라, "되어고"가 안 되면 "돼고"도 안 됩니다.

👉 헷갈릴 때는 자리에 "하"와 "해"를 넣어 보세요.
"하고 싶니"는 말이 되니까 → "되고"
"해요"가 말이 되니까 → "돼요"

#초등받아쓰기 #받아쓰기 #초등맞춤법 #되돼구분 #1학년받아쓰기 #2학년받아쓰기
```

## 03 · 낫다 / 낳다

```
"감기 빨리 낳으세요"

한 번쯤 받아 보셨죠?
아기를 낳으라는 말이 되어 버립니다 😅

병이 없어지는 건 "낫다" → 감기가 다 나았어요
새 생명을 세상에 내보내는 건 "낳다" → 고양이가 새끼를 낳았어요

받침 하나 차이인데 뜻이 완전히 달라집니다.
```

## 04 · 안 / 않

```
"숙제를 하지 안았어요" ❌
"숙제를 하지 않았어요" ⭕

구분법은 생각보다 간단합니다.

"안"은 "아니"의 줄임말 → 뒤의 말과 띄어 씁니다
   오늘은 학교에 안 가요

"않"은 "아니하"의 줄임말 → "-지 않다" 꼴로 붙어 옵니다
   숙제를 하지 않았어요

👉 그 자리를 빼고 읽어서 말이 되면 "안", 안 되면 "않"입니다.

#초등받아쓰기 #받아쓰기 #초등맞춤법 #맞춤법 #안않 #1학년받아쓰기 #2학년받아쓰기
```

## 05 · 꼬치 → 꽃이

```
"꼬치 활짝 피었어요"

1학년 받아쓰기 공책에서 정말 자주 보는 문장입니다.
틀린 게 아니라, 들리는 대로 아주 정직하게 쓴 거예요.

[꼬치]라고 소리 나지만 "꽃이"로 씁니다.
"꽃"이라는 낱말의 모양을 지켜서 적기 때문이에요.

아이가 이렇게 쓴다면 아직 소리와 글자를 잇는 중이라는 뜻입니다.
혼내지 마시고 "꽃"을 먼저 보여 주세요 🌸
```

## 06 · 등굣길

```
"등교길" 아니고 "등굣길"입니다.

낯설죠? 사이시옷이 들어가서 그렇습니다.

두 낱말이 붙으면서 뒷말이 된소리로 나면 사이 ㅅ을 넣어요.
등교 + 길 → 등굣길
바다 + 가 → 바닷가
초 + 불  → 촛불
나무 + 잎 → 나뭇잎

읽을 때 [등교낄]로 소리 나는 게 신호입니다.

#초등받아쓰기 #받아쓰기 #초등맞춤법 #사이시옷 #맞춤법 #2학년받아쓰기
```

## 07 · 왠 / 웬

```
"이게 웬 떡이야?" ⭕
"이게 왠 떡이야?" ❌

한 글자만 외우면 끝납니다.

"왠"이 들어가는 말은 **"왠지" 딱 하나**예요.
"왜인지"가 줄어든 말이라서요.

나머지는 전부 "웬"입니다.
   웬 떡  ·  웬일  ·  웬만하면  ·  웬 사람

👉 "왠지" 말고는 다 "웬"
```

## 08 · 담그다 / 담구다

```
"김치 담궜어요" ❌
"김치 담갔어요" ⭕

기본형이 "담구다"가 아니라 "담그다"라서 그렇습니다.

담그다 + 아요 → 담가요
담그다 + 았어요 → 담갔어요

같은 꼴이 하나 더 있어요.
   잠그다 → 잠가요 (잠궈요 ❌)
   문 잠갔니? 가 맞습니다.
```

## 09 · 앉아서 (겹받침)

```
"꽃밭에 안자서 무엇을 보니?"

저학년이 겹받침에서 가장 많이 넘어집니다.

"앉다"의 받침은 ㄴ과 ㅈ이 함께 있는 ㄵ이에요.
소리는 [안자서]로 나지만 받침 두 개를 다 살려 "앉아서"로 씁니다.

겹받침은 이런 것들이 있어요.
   ㄵ 앉다  ·  ㄺ 맑다  ·  ㅄ 값  ·  ㄼ 넓다  ·  ㄶ 많다

받아쓰기에서 겹받침이 나오기 시작하면 슬슬 어려워지는 구간입니다.
```
