'개'와 '게', '새'와 '세'는 말로 하면 소리가 거의 같아서 귀로는 구분이 안 됩니다. 이런 낱말은 소리가 아니라 문장 속 뜻으로 가려야 해요. 아이에게 알려 줄 수 있는 구분법과 연습 문제를 정리했습니다.

왜 귀로 구분이 안 될까

「ㅐ」와 「ㅔ」는 요즘 말에서 소리가 거의 같습니다. 그래서 받아쓰기에서 소리만 듣고는 정답을 정할 수 없어요. 이럴 때는 어떤 뜻으로 쓰인 낱말인지를 문장에서 찾아야 합니다.

자주 헷갈리는 짝

짝뜻예문
개 / 게개 = 강아지 / 게 = 바다에 사는 동물개가 짖어요. / 게가 옆으로 걸어요.
새 / 세새 = 하늘을 나는 동물, 또는 처음 쓰는 것 / 세 = 셋새가 날아요. / 사과 세 개를 먹었어요.
내 / 네내 = 나의 / 네 = 너의내 책이야. / 네 책이야.

이렇게 구분해 보세요

  1. 뜻을 먼저 떠올려요. 문장에서 강아지인지 바다 동물인지 생각해 보게 하세요.
  2. 「나의」「너의」로 바꿔 봐요. 「내」는 「나의」, 「네」는 「너의」가 줄어든 말이에요. 「내 책」은 「나의 책」, 「네 책」은 「너의 책」으로 바꿔도 말이 됩니다.
  3. 「세 개」처럼 수를 세는 자리는 「세」예요. 「새 개」라고는 하지 않죠.
  4. 틀린 낱말만 모아 문장으로 다시 써 봐요. 낱말 하나만 외우는 것보다 문장 속에서 연습하는 편이 훨씬 오래 기억됩니다.

연습 문제 5개

괄호에 알맞은 낱말을 골라 보세요. 정답은 아래에 있어요.

  1. (개/게)가 꼬리를 흔들어요.
  2. 바닷가에서 (개/게)를 잡았어요.
  3. (새/세) 마리가 나무에 앉아 있어요.
  4. (내/네) 가방은 파란색이야. (말하는 사람의 가방)
  5. 이건 (내/네)가 만든 거야. (듣는 사람이 만든 것)

정답

  1. 개 (강아지)
  2. 게 (바다 동물)
  3. 세 (셋)
  4. 내 (나의)
  5. 네 (너가 → 「네가」)

앱에서는 이렇게 다뤄요
