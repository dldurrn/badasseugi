사이시옷은 규칙을 알아도 어떤 낱말에 쓰는지 헷갈려요. 이 글에서는 규칙은 짧게 하고, 사이시옷을 쓰는 낱말과 쓰지 않는 낱말, 한자어 예외 6개를 낱말 중심으로 정리했어요. 규칙 자체가 궁금하면 아래 연결 글을 보세요.

사이시옷을 쓰는 낱말

두 낱말이 합쳐지면서 뒤 낱말이 된소리로 나거나(바닷가), ㄴ 소리가 덧나는(나뭇잎) 경우에 써요.

낱말구성소리
바닷가바다 + 가[바다까]
냇가내 + 가[내까]
햇빛해 + 빛[해삗]
빗물비 + 물[빈물]
콧물코 + 물[콘물]
나뭇잎나무 + 잎[나문닙]
잇몸이 + 몸[인몸]
뒷모습뒤 + 모습[뒨모습]
아랫집아래 + 집[아래찝]
귓속귀 + 속[귀쏙]
샛길새 + 길[새낄]
촛불초 + 불[초뿔]
깃발기 + 발[기빨]

사이시옷을 쓰지 않는 낱말

낱말까닭
위쪽, 아래쪽, 뒤쪽뒷말이 이미 된소리(ㅉ)로 시작해요
위층, 아래층뒷말이 거센소리(ㅊ)로 시작해요
뒤뜰뒷말이 된소리(ㄸ)로 시작해요
개수, 초점, 대가두 낱말이 모두 한자어예요

「위쪽」을 「윗쪽」, 「뒤쪽」을 「뒷쪽」이라고 쓰는 경우가 많아요. 뒷말이 된소리나 거센소리로 시작하면 사이시옷을 쓰지 않아요.

한자어끼리인데 사이시옷을 쓰는 예외 6개

한자어끼리는 쓰지 않는 것이 원칙이지만 다음 여섯 개만 쓰는 것이 맞아요. 통째로 외워 두세요.

낱말뜻
곳간물건을 넣어 두는 창고
셋방세를 내고 빌려 쓰는 방
숫자수를 나타내는 글자
찻간기차에서 사람이 타는 칸
툇간집채 밖에 달아 낸 칸
횟수돌아오는 차례의 수

헷갈릴 때 확인법

  1. 두 낱말을 소리 내어 이어 읽어 보세요. 뒷말이 된소리나 ㄴ 소리로 바뀌면 사이시옷 후보예요.
  2. 뒷말이 처음부터 된소리·거센소리(ㄲ ㄸ ㅃ ㅆ ㅉ, ㅋ ㅌ ㅍ ㅊ)면 쓰지 않아요.
  3. 두 낱말이 모두 한자어면 쓰지 않아요. 단, 위의 여섯 개는 예외예요.

앱에서도 연습할 수 있어요

받아쓰기 공책에는 「바닷가」 같은 사이시옷 낱말이 든 문장이 있어요. 소리만으로는 ㅅ이 안 들려서 틀리기 쉬운 자리라, 직접 써 보고 채점받으면 기억에 오래 남아요.
