# 받아쓰기 공책 소개와 사용법, 아이 혼자 하는 받아쓰기 앱

## 티스토리
- 제목: 받아쓰기 공책 소개와 사용법, 아이 혼자 하는 받아쓰기 앱
- 카테고리: 서비스 > 받아쓰기 공책
- 주소(슬러그): dictation-app-guide  ← 글끼리 링크가 이 주소를 씁니다. 반드시 그대로
- 태그: 받아쓰기앱, 받아쓰기공책, 초등받아쓰기, 받아쓰기연습, 초등학습앱, 맞춤법앱, 받아쓰기혼자
- 방법: 글쓰기 → [기본모드 → HTML] → `tistory.html` **전체**를 복사해 붙여 넣기 → 기본모드로 돌아와서 노란 상자 자리에 이미지를 올리고 상자는 지우기
- 주의: 이 파일에는 발행 정보 주석이 없습니다. 제목·카테고리·슬러그·태그는 이 문서를 보고 직접 입력하세요.

## 네이버 블로그
- 제목: 초등 받아쓰기 앱 '받아쓰기 공책' 소개 | 아이 혼자 듣고 쓰고 채점받아요
- 태그(10개): #받아쓰기앱 #초등받아쓰기앱 #받아쓰기공책 #받아쓰기연습 #초등학습앱 #맞춤법앱 #받아쓰기혼자 #초등1학년 #초등공부 #학습습관
- 방법: `naver.html`을 Chrome으로 열기 → Ctrl+A, Ctrl+C → 스마트에디터에서 Ctrl+V → 노란 상자 자리에 이미지를 올리고 상자는 지우기
- 맨 위 이미지(대표)를 **대표 사진**으로 지정
- 티스토리에 올린 뒤 **3일 이상 지나서** 올리세요 (같은 내용을 같은 날 올리면 중복 문서로 밀릴 수 있습니다)
- 「함께 보면 좋은 글」은 네이버에 올린 다른 글 주소로 직접 연결하세요
