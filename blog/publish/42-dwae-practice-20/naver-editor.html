되와 돼는 규칙을 알아도 문장 속에서 틀려요. 되어를 넣어 말이 되면 돼, 안 되면 되. 연습 문제 20개와 정답, 해설을 한 번에 정리했어요.



규칙 한 줄


「돼」는 「되어」의 준말이에요. 괄호 자리에 「되어」를 넣어 보고 어색하지 않으면 「돼」, 어색하면 「되」를 써요. 또 「하」를 넣어 말이 되면 「되」, 「해」를 넣어 말이 되면 「돼」라고 기억해도 돼요.



문제 (괄호에 알맞은 것을 고르세요)


1. 이제 가도 ( 되 / 돼 )요.

2. 나는 어른이 ( 되 / 돼 )고 싶어요.

3. 숙제를 다 하면 ( 되 / 돼 )?

4. 그렇게 하면 안 ( 되 / 돼 ).

5. 나는 의사가 ( 되 / 돼 )겠다고 말했어요.

6. 문이 열려 ( 되 / 돼 ) 있어요.

7. 약속이 취소( 되 / 돼 )서 아쉬워요.

8. 이 일이 어떻게 ( 되 / 돼 )는지 궁금해요.

9. 다음에 해도 ( 되 / 돼 )?

10. 두 시간이면 ( 되 / 돼 )나요?

11. 곧 ( 되 / 돼 )니까 기다려 주세요.

12. 걱정이 ( 되 / 돼 )요.

13. 이제 다 ( 됐 / 됬 )어요.

14. 준비가 ( 됐 / 됬 )으면 출발하자.

15. 그러면 안 ( 되 / 돼 )요.

16. 하고 싶은 대로 ( 되 / 돼 )길 바라요.

17. 그렇게 하면 ( 되 / 돼 )지.

18. 너무 늦어서 안 ( 되 / 돼 )겠다.

19. 정리가 ( 되 / 돼 ) 있어요.

20. 쓰고 싶은 대로 써도 ( 되 / 돼 )요.



정답과 해설


• 돼 — 되어요

• 되 — 되고 (「되어고」는 말이 안 돼요)

• 돼 — 되어?

• 돼 — 안 되어

• 되 — 되겠다 (「되어겠다」는 안 돼요)

• 돼 — 되어 있어요

• 돼 — 취소되어서

• 되 — 되는지

• 돼 — 되어도 돼?

• 되 — 되나요

• 되 — 되니까

• 돼 — 걱정이 되어요

• 됐 — 「됬」은 없는 글자예요. 되었 → 됐

• 됐 — 되었으면 → 됐으면

• 돼 — 안 되어요

• 되 — 되길

• 되 — 되지

• 되 — 되겠다

• 돼 — 되어 있어요

• 돼 — 되어요



틀린 만큼 짚어 보세요


• 되고·되는·되겠·되지·되니·되길처럼 뒤에 이어지는 말이 붙으면 대부분 「되」예요.

• 돼요·돼서·돼·돼도처럼 어미가 바로 붙으면 대부분 「돼」예요.

• 「됬」「됬어」는 없는 표기예요. 항상 「됐」이에요.



앱에서도 연습할 수 있어요


받아쓰기 공책에는 「되/돼」를 고르는 맞춤법 문제도 있고, 받아쓰기에서 직접 쓰는 문장도 있어요. 틀린 문제는 오답노트에 쌓여서 같은 규칙의 다른 문제로 다시 풀어 볼 수 있어요.
