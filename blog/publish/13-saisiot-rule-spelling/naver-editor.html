촛불과 바닷가에는 ㅅ을 쓰는데 인사말에는 왜 안 쓸까요? 한 가지 질문만 던지면 구분이 됩니다. 아이에게 그대로 알려 줄 수 있게 사이시옷 규칙을 정리했어요.



한 줄로 정리하면


두 낱말이 합쳐질 때 소리가 바뀌면 사이시옷을 씁니다. 소리가 그대로면 쓰지 않아요. 합쳐진 말이라고 해서 무조건 쓰는 게 아닙니다.



이렇게 확인해 보세요


낱말을 소리 내어 읽어 보고 뒤 글자가 세게(된소리) 나거나, 「ㄴ」 소리가 덧나는지 들어 보세요.


• 촛불 (초 + 불) — [초뿔] — 「불」이 세게 나요 — 씀

• 바닷가 (바다 + 가) — [바다까] — 「가」가 세게 나요 — 씀

• 나뭇잎 (나무 + 잎) — [나문닙] — 「ㄴ」이 덧나요 — 씀

• 인사말 (인사 + 말) — [인사말] — 소리가 안 변해요 — 안 씀

• 머리말 (머리 + 말) — [머리말] — 소리가 안 변해요 — 안 씀



자주 나오는 사이시옷 낱말


• 촛불, 바닷가, 냇가, 나뭇잎, 깻잎, 잇몸, 칫솔

• 모두 앞말이 모음으로 끝나는 합성어이고, 읽을 때 뒤의 소리가 바뀝니다.



예외: 한자어끼리는 안 써요


두 낱말이 모두 한자어이면 사이시옷을 쓰지 않아요. 그래서 개수(個數), 초점(焦點), 대가(代價)에는 ㅅ이 없습니다. 다만 곳간, 셋방, 숫자, 찻간, 툇간, 횟수 여섯 개만 한자어끼리인데도 사이시옷을 써요. 이 여섯은 외워 두세요.


• 초불 / 촛뿔 — 촛불

• 바다가 / 바다까 — 바닷가

• 갯수 — 개수 (한자어끼리라 ㅅ이 없어요)

• 회수 (줄넘기 ○회) — 횟수 (여섯 예외 중 하나)

• 인삿말 — 인사말



연습 문제 5개


알맞은 낱말을 골라 보세요. 정답은 아래에 있어요.


1. 생일에 (초불 / 촛불)을 켰어요.

2. (바다가 / 바닷가)에서 조개를 주웠어요.

3. 사탕 (갯수 / 개수)를 세어 봐요.

4. 줄넘기 (회수 / 횟수)를 세어요.

5. 반장이 (인삿말 / 인사말)을 했어요.


정답


1. 촛불 ([초뿔])

2. 바닷가 ([바다까])

3. 개수 (한자어끼리)

4. 횟수 (여섯 예외)

5. 인사말 (소리가 안 변해요)
