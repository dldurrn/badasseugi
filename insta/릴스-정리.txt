새 작업 공간에서 이어 가기
--------------------------------------------------------------------
  1) git clone https://github.com/dldurrn/badasseugi.git  (또는 git pull)
  2) npm install          ← ffmpeg-static · sharp 가 여기서 깔립니다
  3) 먼저 읽을 것
       insta/릴스-정리.txt            지금 이 파일 — 만든 것·후보
       scripts/릴스-만드는-법.md      훅 쓰는 법·금지 표현·형식
       insta/reel*/캡션.md            캡션 말투 참고
  4) 만들기
       node scripts/make-reel.cjs --list      문항 id 보기
       node scripts/make-reel.cjs             REELS 배열의 세 편 → insta/reel/
       node scripts/make-feature-reel.cjs     기능 소개 → insta/feature-reel/
  ※ 글꼴은 Windows 기본 글꼴(바탕·맑은 고딕)을 씁니다. Mac 에서는 모양이 달라집니다.
  ※ 영상·이미지(mp4·png)는 git 에 없습니다. 위 명령으로 다시 그리면 똑같이 나옵니다.
